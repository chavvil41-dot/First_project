# Contributing

Thanks for wanting to contribute! For now this repository is mainly for my own learning.
If you'd like to suggest improvements or add exercises, open an issue or a pull request.

- Put C files under `src/c/`, C++ files under `src/cpp/`, Java under `src/java/`, Python under `src/python/`.
- Keep one small exercise per file.
- Name C files `exercise_<n>.c` and add a comment at the top explaining the exercise.
